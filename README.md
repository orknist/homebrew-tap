# Orknist Tap

## How do I install these formulae?

`brew install orknist/tap/<formula>`

Or `brew tap orknist/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "orknist/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
